\begin{abstract}
\noindent We study satellite image gap filling and quantify how local scene complexity affects reconstruction quality.
Using 15 classical interpolation methods and five deep learning baselines, we evaluate PSNR, SSIM, RMSE, SAM, and ERGAS across noise levels, sensors, and entropy windows.
The entropy-quality relationship is method- and scale-dependent rather than monotonic, which motivates treating each entropy window independently.
The results support entropy as a practical auxiliary signal for method selection and for prioritizing difficult patches.
\end{abstract}
